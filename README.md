## How to publish on GitHub Pages from mobile:
1. Create new repo on github.com (Public)
2. Tap Add file → Upload files
3. Upload EVERYTHING from this folder (Aliza.html, index.html, images/, music/)
4. Go to Settings → Pages → Source: main / root → Save
5. Wait 1-2 mins → your link: https://YOURNAME.github.io/REPO-NAME/
6. Direct link: https://YOURNAME.github.io/REPO-NAME/Aliza.html
